### 🎭 Animation Sequence

When menu opens:
1. **0.1s** - First item fades & slides in
2. **0.15s** - Second item appears
3. **0.2s** - Third item
4. **0.25s** - Fourth item
5. **0.3s** - Fifth item
6. **0.35s** - Order button appears

Result: **Beautiful cascading effect!**

## 📐 Technical Details

### Colors
- Background: `rgba(10, 14, 13, 0.98)` with green tinge
- Border: `rgba(212, 175, 55, 0.2)` - soft gold
- Menu items: `rgba(212, 175, 55, 0.05)` - subtle gold
- Hover: `rgba(212, 175, 55, 0.15)` - enhanced gold

### Effects
- Backdrop filter: `blur(25px) saturate(180%)`
- Box shadow: `0 15px 40px rgba(0, 0, 0, 0.6)`
- Border radius: `25px` (bottom only)
- Transform: `translateY(-20px)` to `translateY(0)`

### Responsive
- Appears at **768px and below**
- Full width on mobile
- Perfectly aligned with nav bar
- Z-index managed for proper layering
